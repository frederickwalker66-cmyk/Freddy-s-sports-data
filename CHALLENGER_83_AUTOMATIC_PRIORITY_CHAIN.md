# Upgrade 83: sequential research workflow

After successful main-branch prospective captures, the eight-sport source preflight runs its established stages in order: original source capture, game identity, market diagnostics, native training readiness, calibration, frozen Champion authentication, and final release gate.

The new trigger does not add a cron schedule. GitHub Actions may queue or delay runs. A run records the upstream run ID and independently captures new source bytes rather than claiming that prior odds are current.

The final artifact includes automatic_chain_provenance.json and automatic_chain_status.json. Research-only evidence cannot be promoted to certified predictions or wagers. Champion-001 remains frozen. Missing independently authenticated native data, holdouts, direct bookmaker quotes and calibration continue to block release.
